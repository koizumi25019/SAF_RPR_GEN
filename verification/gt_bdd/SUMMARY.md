## 検証手法（env `GT_BDD=1`, `fault_detection_prob.c` の `GT_Check`）

SAT/CNF/XID/キューブ列挙/支配流用を**一切使わない**独立グラウンドトゥルース。

- 正常回路の全ネット BDD を**1回だけ**構築（変数 i ↔ pi[i]、CUDD sift 動的並べ替え）。
- 故障ごとに故障注入した**TFOコーンのみ**故障回路 BDD を構築。
- 検出関数 **D_f = OR_PO(正常 XOR 故障)** を厳密に得て、パイプラインのキューブ和集合と
  **同一マネージャ内のポインタ比較**で照合：
  - **sound**（和集合 ⊆ D_f）… `-limit` 打ち切り（complete=0）でも常に成立すべき
  - **exact**（和集合 = D_f）… complete=1 なら成立すべき
- ミンターム数の比較ではなく**集合の等価判定**なので、シミュレーションと違い誤差ゼロ。
- 検証器自身の妥当性: c17a ゴールデン一致＋独立シミュレーション(FdpBySim)との三重照合で確認。
- 診断: `GT_VERBOSE=1`（全故障出力）、`GT_CUBES=1`（非健全キューブの特定＋
  「どのXを1ビット固定すれば健全になるか」の候補列挙 → バグ箇所の特定に決定的だった）。

## 修正1: EssentialAssignment の過小評価・偽冗長（完全性違反）

**ファイル**: `src/fdp/essential_assignment.c` `unique_sentization`
**症状**: complete=1 なのにキューブ和集合 ⊊ D_f（s510で40故障、s5378で26故障）。
最悪は**偽冗長**（s5378 `n1447gat_n1618gat_B/sa0`: cubes=0 で冗長判定だが真FDP=0.094）。

**機構**: 唯一感化は「BFSフロンティアが1本に絞られた地点＝支配点」の側面入力に
非制御値を**単位節**として課す。しかしフロンティアは「まだ観測点に達していない経路」
しか覆っていない。**先に PO/PPO で終端した検出経路があると、残りフロンティアが1本でも
それは全検出経路の支配点ではない**。そこで側面入力を固定すると、先に終端した観測点
経由の検出テストが CNF から排除される（検出ソルバ自体が過小: s510 II104/sa0 で
sim=0.1135 vs detSolver=0.0352、det+undet=0.92<1 が証拠）。

**修正の意図**: 支配点判定が正当なのは「全観測点が当該ゲートの下流にある」場合のみ。
観測点を一度でも通過（PO を dequeue / DFF 入力に到達）したら以降の割り当てを禁止する
`obs_seen` フラグを追加。割り当ての機会は減るが、健全性（必須割り当てのみ課す）が回復。

**検証**: 修正前に `MDC_NOEA=1`（EA全無効）で全過小が消えることで原因を確定 →
修正後は **EA有効のまま** s510/s5378 の全過小解消、c17a ゴールデン一致。

## 修正2: XID J-frontier 正当化の取りこぼし（健全性違反・過大評価）

**ファイル**: `src/fdp/xid/xid_backward_imp_limited.c` `xid_bimp_limited_univ`
**症状**: キューブが非検出ミンタームを含む（修正前: s298:6 / s641:9 / s713:10 / s5378:28
のうち大半）。例: s298 G14/sa1 で fdp 0.387 vs 真値 0.366。

**機構**: 正当化候補が複数ある要求は J-frontier（jus_q）に送られ、本関数が最終決定する。
ところが (a) 候補フィルタが `normal_2value != c_val || fault_2value != c_val → skip` と
**正常側・故障側の合成条件**になっており、D を運ぶ入力（片側だけ制御値）が**両側の探索から**
消える、(b) コミット条件が `n_cnt >= 2` で、**候補が1つ残った（＝含意として確定すべき）
ケースで何もせず要求が黙って消滅**する。結果、必須PIがXのまま出力される。
（実例: s298 G14/sa1 cube#16 — G44=NOR3 の側面 G53 の normal=0 要求が、候補 G26 が
D持ちでフィルタ落ち→残り G27 1つ→コミットされず→G28→G130→**G0=0 が丸ごと消失**。
`GT_CUBES=1` が「fix G0=0 would be sound」と特定した。）

**修正の意図**: 探索を正常側・故障側で**独立**に行い（片側だけ制御値を持つ入力もその側の
候補として有効）、**候補が1つでも残っていれば必ずコミット**する。コミットする3値は常に
SATモデルの2値に一致する（モデル誘導）ため、既存の要求と矛盾せず完全性も保たれる。

**検証**: G14/sa1 が厳密一致化。s298 6→2 / s641 9→2 / s713 10→2 / s5378 28→20。

## 修正3: 故障サイトを通る故障側後方含意の遮断（健全性違反・過大評価）

**ファイル**: `src/fdp/xid/XID.h` / `XID.c` / `xid_backward_imp.c` / `xid_backward_imp_limited.c`
**症状**: 修正2の後も残った過大評価（s298:2 / s641:2 / s713:2 / s1494:2 / s5378:20）。
最小再現: s298 `G50_G26_B/sa1`（キューブ1本、fdp 0.125 vs 真値 0.117）。

**機構**: 分岐故障では故障サイト＝FOUTネット。X-filling がサイトに到達すると bwd_q に
入れ、`xid_bimp_buf` が**サイトの故障側3値（＝縮退値1）をステムに逆伝搬**する。
しかしステムの真の故障値は 0（縮退はサイトの公理であり、駆動側から正当化される値では
ない）。汚染されたステム故障値が前方含意で**別の再収斂経路**（G47/G48）の故障側要求を
「偽正当化」し、本来必要な care ビット（G10=0 等）が消える。
（旧修正 = Xfilling 冒頭の `ED_push_Xpath(fsig)` はサイト自身の値の**上書き**は防ぐが、
サイトを**通過する逆含意**は防げていなかった。）

**修正の意図**: `xid_backward_imp` / `xid_backward_imp_limited` に `fsig_id` を渡し、
**サイトでは f3v を X にマスク**してから含意する。正常側（活性化要求）の逆伝搬は正常回路
の含意として正当なので維持。縮退値はどこからも正当化不要、が原則。

**検証**: G50_G26_B/sa1・G14/sa1 とも厳密一致化 → **全9回路 ALL VERIFIED**（上表）。

## なぜ c17a は全故障で正しく、少し大きい回路で壊れたのか（完全な説明）

3バグとも**回路サイズではなく特定の構造パターン**で決定論的に発火する：

1. EA: 「TFO の一部経路が先に観測点で終端し、その後フロンティアが1本に合流する」構造。
2. XID J-frontier: 「1つの正当化要求を複数入力が満たし、その一部が故障コーン内（D持ち）」
   という再収斂構造（かつ正当化が選択的＝jus_q を経由する場合のみ）。
3. XID サイト逆含意: 「ステム→複数分岐→再収斂で、汚染ステム値が別経路の側面条件を
   偽正当化できる」構造（分岐故障のみ）。

c17a（ゲート6個・PO2・深さ3）にはこれらのパターンが**存在しない**ため全故障で正しい。
同様に s27/s208/s344 も（中規模だが）パターン非含有で最初から ALL VERIFIED だった。
つまり「サイズとともに単調に壊れる」のではなく、**壊れる構造を含む確率がサイズとともに
1に近づく**。s510 は II* 系制御ロジックの構造1が大量にあり、s5378 は再収斂が多く
構造2・3を多数含んでいた。

この説明が「完全」であることの根拠: GT_BDD は全故障を**厳密に**検査しており、
3バグの修正だけで**全回路の全故障が ALL VERIFIED になった** = 不一致は3バグで
過不足なく説明され、未知の原因は残っていない（検査した回路群の範囲で）。

教訓: 小回路のゴールデン一致はこの種の含意ヒューリスティックのバグを検出できない。
**挙動を変える変更は `GT_BDD=1` で中規模回路を流す**こと（回帰手順は下記）。

## 回帰手順

NO_DISCORD=1 GT_BDD=1 ./main_release -set ../verification/gt_bdd/s5378.set
