# CORE の X 全展開による独立故障シミュレーション

実施日: 2026-10-06（Asia/Tokyo）。対象は縮退故障（SAF）の小規模4回路。
全代表故障、無制限、支配キューブ流用 off、追加 core 検証 off。

## 結果

| 回路 | 入力数 | 代表故障数 | キューブ数 | core直後の展開パターン延べ数 | 極小化後の展開パターン延べ数 | 非検出を含むキューブ |
|---|---:|---:|---:|---:|---:|---:|
| c17a | 5 | 22 | 53 | 258 | 300 | 0 |
| s27_C | 7 | 32 | 104 | 2,026 | 2,156 | 0 |
| s208_C | 19 | 215 | 1,272 | 38,709,632 | 48,821,632 | 0 |
| s298_C | 17 | 308 | 1,115 | 10,164,480 | 13,178,368 | 0 |
| 合計 | — | 577 | 2,544 | 48,876,396 | 62,002,456 | 0 |

core 抽出直後・極小化後とも、X の全ての 0/1 割当てが対象故障を検出した。
キューブ間で同じ入力パターンを含む場合もあるため、展開パターン数は重複を含む延べ数。
ランダムサンプリングは行っていない。

各代表故障について全入力空間を正常／故障回路で評価した（合計153,096,896故障・入力組）。
極小化後の全キューブの和集合と、シミュレーションで得た検出パターン集合も全故障で一致した。
検出パターン数から計算した FDP と出力 CSV の FDP も一致した。
計測時の CSV と今回の CSV は、全行・全列が一致した。

## 方法と独立性

- `capture_cubes.c` は検証専用の GNU リンカ `--wrap` を使い、現在の C ソースから
  別バイナリを作る。製品のソース・通常バイナリ・CMake 対象は変更しない。
- `ccadical_failed` の戻り値をそのまま返しつつ、初期 core と最終キューブを記録する。
  記録した input/core/prime のビット数が本体の統計と一致することも確認する。
- `simulate_expanded.py` は元の Verilog のゲートと接続を独立に読む。
  正常値と、対象の stem／ゲート入力 branch／PO branch に縮退値を注入した故障値を計算する。
  少なくとも一つの PO の値が異なる入力を検出パターンとする。
- Python の整数の各ビットを一つの完全入力割当てに対応させ、2値ゲート演算をビット並列実行する。
  全 `2^n` 入力を含むため、各キューブの X 全展開も漏れなく含まれる。
  キューブの展開集合の大きさが `2^(X数)` であることも確認する。
- 判定に本体の CNF・非検出 SAT オラクル・BDD 検証器は使わない。
  core の生成には本体の C 実装と CaDiCaL を使う。
- 非健全な all-X キューブを検証入力に混ぜる負例も確認した。
  c17a の a/sa1 で非検出入力 `10000`（ダンプした PI 順）が反例として報告される。

この検証は小規模 SAF の結果であり、中規模・TDF・低消費電力制約の全展開検証ではない。
検証スクリプトは最大20入力の組合せ回路・対応する基本ゲートに限定している。

## 再現

同梱 CaDiCaL/CUDD をビルド済みの Linux/GNU ツールチェーンで実行する。

```bash
python3 verification/paper_core/simulate_expanded.py
# 前の性能実験の CSV との一致も検査する場合（その出力がローカルにある場合）
python3 verification/paper_core/simulate_expanded.py \
  --historical output/paper_core_benchmark/20261005T122952Z \
  --output output/paper_core_simulation_new
```

既に cover ファイルがある出力先への再実行は拒否するため、再実行は `--output` で新しい場所を指定する。
今回の生データは `output/paper_core_simulation_final/`。
Git に保存した集計は `results/simulation_summary.json`、577故障ごとの結果は
`results/simulation_faults.json`。

## グラフ用 Excel

`paper_core_comparison.xlsx` に、過去の小規模4回路＋中規模2回路を数値表として保存した。
実行時間、キューブ数、故障完了、X率、判定回数、時間内訳、中規模FDP比較、全60測定値、
シミュレーション、測定条件の10シート。グラフは含めない。
割合は文字列ではなく数値0〜1で保存し、Excel の百分率表示を設定している。
未測定の中規模 XID X率は空欄としており、0と区別する。

Excel の入力スナップショット `results/comparison_data.json` も Git に保存した。
元の無視対象 `output/` が無くても Excel は再生成できる。

```bash
# Python の openpyxl が必要
python3 verification/paper_core/export_excel.py
```
