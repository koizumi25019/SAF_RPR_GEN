< Automatic Seed Generator using a compatible fault set >	designer T.Sone
両立可能故障集合を用いた複数RPR縮退故障に対するシード生成

■コマンド
【入力】
-z		:スクリプトファイル


【出力】



■サンプルコマンド
-------------------------------------------------
スクリプトファイル		：s5378_C.set
-------------------------------------------------
ASG.exe -z s5378_C.set

■スクリプトコマンド
-n	：【入力】回路ファイル
-f	：【入力】RPR故障集合ファイル
-x	：【入力】フェーズシフタファイル
-c	：【入力】スキャンチェインファイル
-e	：【入力】必須割当て情報ファイル
-l	：【出力】グラフログファイル
-p	：【出力】外部ピンファイル
-s	：【出力】シードファイル
-t	：【出力】テストパターンファイル
-u	：【出力】シード生成不能故障ファイル
-o	：【入力】モード（STTG or MTTG）
-m	：【入力】モード（シード生成　or テスト生成）



■注意事項
必須割当て情報ファイルは必須ではない。与えない場合両立可能故障集合を用いずシード生成を行う。
基本的にLFSRは100ビットで動作させる。それ以外で動作確認はしていない。
