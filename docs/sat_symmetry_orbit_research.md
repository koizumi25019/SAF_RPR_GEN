# 追加調査: 対称なキューブの集合を単位とする完全列挙

調査日: 2026-10-22。文献と既存試作記録の照合、人工例の全数確認。
b15での対称性検出・性能実験、本体の変更は行っていない。

## 今回の結論

前回の[被覆同時合成・列生成](sat_global_cover_research.md)に加える候補は、
**故障検出関数の対称性を証明し、一つのテストキューブから対称なキューブ群を生成する方法**。
直接の参考文献として、FMCAD 2023のQSMには素項の「軌道」を単位とする列挙がある。
軌道とは、入力の置換を適用して得られるキューブの集合である。

SATテスト生成 → DC判定 → 生成被覆BDDという流れを維持できる。
ただし、DC段階の出力を「単独の0/1/Xキューブ」から「代表キューブと証明済み置換群」へ拡張する。
通常キューブ数を30以下にする方法と、SAT/DCで代表を生成する回数を減らす方法は区別する。
同じ実行時間・メモリ予算でcompleteが増えるかが最終評価になる。

任意の回路で有効な対称性が存在する保証はない。特に故障注入は正常回路の対称性を壊し得る。
今回の文献からb15の完全化を断言することはできない。

## 1. 直接参考になる論文

Fazekas, Goel, Sakallah,
**SAT-Based Quantified Symmetric Minimization of the Reachable States of Distributed Protocols**,
FMCAD 2023。
[著者公開PDF](https://kfazekas.github.io/papers/FazekasGoelSakallah-FMCAD23.pdf)

Section III.A / Algorithm 1は、一つの素項をSATで取得し、その対称な素項をまとめた軌道を登録して、
以降の探索から除外する。Section III.Bでは軌道を単位とする被覆最小化を行う。
これは普通のSATに対称性除去節を加えるだけの話とは異なり、被覆そのものを集合単位で扱う先行例である。

原論文は分散プロトコルが対象であり、前段に到達状態のBDD計算、後段に量化式の推論と最適化がある。
FDPへ全手順を移植する提案ではない。借りる部分は「一つの素項から軌道を生成する」操作である。
また、全素項軌道の列挙や最小被覆の最適化はFDPの完全被覆に必須ではない。
以下のFDP接続、個数制約への変換、実験設計は今回の応用案である。

## 2. FDPへの接続と厳密性

故障fの真の検出関数をD(x)、生成済み被覆をU(x)とする。
入力置換gについて、次をSATで証明する。

`D(x) XOR D(g(x))` がUNSAT。

gを生成元とする群をGとする。通常のDC判定で `C => D` が証明済みなら、
どのgについても `g(C) => D` となる。そこで次の領域を登録できる。

`R = OR_{g in G} g(C)`

実行手順:

1. テスト生成SATで `D AND NOT U` のモデルを得る。
2. DC判定でモデルを通常キューブCへ拡大する。
3. 証明済み対称性からRを作り、生成被覆BDDを `U := U OR R` と更新する。
4. 次のテスト生成SATからR全体を除外する。
5. `D AND NOT U` がUNSATならcomplete=1とする。

SATへ戻す禁止条件は、少数の像なら通常のキューブ禁止節を使える。
像が多い場合はRまたは生成済みUのBDDをTseitin CNFへ符号化し、根を否定する方式が候補になる。
BDD blocker圧縮自体は既存の `next_approaches/SUMMARY.md` にある案で、新規とは扱わない。

必要な区別:

- 対称性は、各故障のDについて成立する必要がある。正常回路の入力対称性だけでは不十分。
- CNFの内部変数だけを入れ替える対称性は、異なるPIキューブを増やさない。
- 構文的CNF対称性を使う場合、PI集合と内部変数集合を保存する写像であることを確認する。
- Dの同値検査には、正常・故障回路の機能を表す完全なmiterを使う。
  検出を強制する励起制約、EssentialAssignment、D-chain制約を残したままdを反転しない。
- 通常のsymmetry breakingで代表解だけを残し、そのまま数えるとFDPを過小評価する。
- キューブの像は重なり得る。`軌道の要素数 × P(C)`では数えず、BDDの和集合を数える。
- 対称性検査がUNKNOWNなら、その置換は採用しない。

## 3. 大きな軌道を個数制約で表す

入力集合Sの任意の置換がDを保存すると証明できた場合を考える。
CがS内でa個を1、b個を0に固定し、残りをXにしているとする。
S外のリテラルをKとすると、その軌道は次の式に厳密に等しい。

`R = K AND [a <= SUM_{i in S} x_i <= |S|-b]`

理由: 軌道内のどれかのキューブを満たすために必要十分なのは、a個以上の1とb個以上の0があること。
置換すべてを列挙せず、個数制約のBDDを作れる。単一の個数区間は通常の入力順でもO(|S|^2)個の
状態で構築できる。ただし複数軌道のBDD和集合が小さいとは限らない。

一般の置換群、ビット列単位の交換、符号付き置換へ、この式を無条件に適用してはいけない。
任意の置換を許す対称集合であることが前提である。

### 30通常キューブでは不可能だが、1軌道で完了する人工例

`D(x_1,...,x_8) = [SUM x_i >= 4]`

| 指標 | 全数確認した値 |
|---|---:|
| 検出入力 | 163 / 256 |
| 通常キューブの最小被覆数 | 70 |
| `1111XXXX`から生成できる被覆軌道 | 1 |
| この軌道の和集合のROBDD非終端ノード | 20 |

1がちょうど4個の検出入力は70個ある。一つの健全な通常キューブがそのうち二つを含むと、
両入力で共通の1だけを残した、1が3個以下の入力も含んでしまう。従って最低70キューブが必要。
4個の1を固定する全70キューブで実際に覆えるため、この下限は達成される。
一方、全入力置換が対称なので、`1111XXXX`の軌道一つでD全体を表せる。

さらに独立な12入力をすべて1に固定する条件をANDすると、通常キューブの必要数70は保たれ、
FDPは `163/1048576 = 0.00015544891357421875` となる。
**低いFDPと、小さい通常キューブ被覆は別の性質**である。

確認内容: 8入力の全256割当てと全6,561キューブで健全性・下限を確認。
生成70キューブのORだけからROBDDを構成し、非終端20ノードを確認した。
さらにa+b<=8の全45組で、軌道と上記個数区間が256割当て上で一致することを確認した。
これらは表現上の効果を示す人工例であり、b15の測定結果ではない。

## 4. 対称性を見つける文献と、条件付き対称性

Zhang, Mishchenko, Brayton, Chrzanowska-Jeske,
**Symmetry Detection for Large Boolean Functions using Circuit Representation, Simulation, and Satisfiability**,
DAC 2006。
[会議論文PDF](https://www.cs.york.ac.uk/rts/docs/DAC-1964-2006/PAPERS/2006/DAC06/PDFFILES/P0510.PDF)

回路構造で対称な入力組を見つけ、シミュレーションで非対称な組を落とし、残りをSATで証明する。
回路全体のBDDを事前構築せずに関数の入力対称性を調べる点が適合する。
FDPでは同じ検出関数についてこの順で候補を絞り、費用の大きい全入力ペアSATを避けたい。

全体では非対称でも、少数の入力条件pを固定すると対称になる場合がある。
Kopp, Singla, Kautz,
**Conditional Term Equivalent Symmetry Breaking for SAT**, AAAI 2017 Workshop。
[公式PDF](https://cdn.aaai.org/ocs/ws/ws0338/15140-68451-1-PB.pdf)
は、部分割当ての後に現れる隠れた対称性をSATで利用する研究である。

FDPへの応用案は、pで固定した入力を動かさないgについて
`p AND (D(x) XOR D(g(x)))` のUNSATを証明し、
`p AND C`から `p AND OR_g g(C)` へ広げること。
例として `D = (s AND [SUM x_i >= 4]) OR (NOT s AND x_1)` は全体ではx_1とx_2を交換できないが、
s=1の領域では交換できる。pを省略して像を追加してはいけない。

原論文は関係的SAT問題のsymmetry breakingであり、上記FDP被覆は未検証の応用案。
制御入力の候補を1〜2個程度に絞った探索から始める。任意の条件を大量に分岐させると、
既存のShannon分割と同様に分岐数の爆発を招く。

## 5. 既存試作との違い

`verification`ブランチの各SUMMARYと会話実験要約を照合した。
`linear_coordinates`と`linear_scaling`には対称関数・NPN分類の文献があり、
入力置換・反転を用いた**異なる故障間の被覆再利用**は実装済み。
したがって「対称性を使うこと自体が初めて」とは主張しない。

今回の狙いは、**同じ故障の未被覆部分を、一つのキューブの対称像で埋めること**である。
この軌道閉包と条件付き軌道被覆を実験した記録は、確認した要約では見つからなかった。
既存の少数ビット状態集合・predicate SOPとも表現力は重なるが、全状態や多数のパイロットキューブを
集めず、対称性の証明から大きい集合を生成する点を比較対象にする。

dual-rail研究を読む際には、`F(x,z)`自体のimplicantと、`D(x)=EXISTS z F(x,z)`のimplicantを区別する。
後者では未固定PIの値に応じて内部変数zを変えてよい。
例えば `F=(z IFF x)` の射影は恒真なのでxはXにできるが、CNFの各節を直接満たすpartial assignment
では同じ省略を表せない。内部変数付き回路CNFへdual-railを適用するだけで、最大の意味論的DCが
得られるとは限らない。この点で既存のsemantic DC比較を省略しない。

## 7. b15で先に確かめること

最初の実験は、QSM全体の実装よりも**有効な対称性の頻度と軌道の利益の測定**がよい。

1. complete=0の代表故障から、回路位置・支持サイズの偏りを抑えた固定標本を選ぶ。
2. 機能的に無関係な入力だけの交換は除き、検出関数の支持内で対称性候補を探す。
3. 全体の対称性と、少数条件付きの対称性を分けて証明する。
4. 最初の数キューブから、像の異なる数、追加被覆、BDDノード増加、証明費用を測る。
5. 有効な標本のみ軌道を含めて完全列挙し、元回路SATで健全性と完全性を確認する。

記録する値は、通常キューブ相当数、代表生成数、SAT/DC呼出し数、対称性検出時間、
BDD時間、メモリ、complete数。前処理時間も含めた同一予算で比較する。
有効な対称性が少ない、像がほぼ既被覆、BDDが膨らむ場合は、この方向の優先度を下げる。

特に、軌道1個をcube_cnt=1と書くだけで「limit30のまま改善」と報告してはいけない。
三段階を維持しつつ、列挙単位の変更で指数個の個別処理を回避できたかを検証する研究になる。
