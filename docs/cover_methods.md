今回の3手法は、上のどれとも「何を変えるか」が異なる。

| 手法 | 変えるもの | 出力する単位 | 既出との違い |
|---|---|---|---|
| A 順序付き被覆 | キューブの**健全性の意味**（先行キューブを前提にしてよい） | 通常の 0/1/X キューブ（ラベルと順序付き） | DUAL は両側とも純粋なキューブ。先行分をドントケアにする拡大は記録にない |
| B 擬似キューブ | ドントケア判定の**操作**（削除に加えて2条件のパリティ併合） | パリティ制約の積 | 線形座標は故障ごとに基底を先に固定する。領域ごとに併合を選ぶ方式は記録にない |
| C 窓関係 | 一般化の**手段**（窓内は全数シミュレーション、窓外はSAT反例） | 窓外キューブ×窓内の任意関係 | 多値領域は幅6・64状態までを状態ごとのSATで拡大。幅10〜16の窓を表ごと扱う方式は記録にない |

3手法とも SAT によるパターン生成 → ドントケア判定 → 生成領域のBDD和集合、という三段階を保つ。
回路の検出関数を直接BDDにしない。完了は従来どおり残余のUNSATで判定する。

## 3. 共通の前提

- 検出側ソルバ P: 既存のテスト生成CNF（励起、Dチェーン、必須割当てを含む）。
- 非検出オラクル N: 正常回路＋故障回路＋「全観測点が一致」。励起・Dチェーン・必須割当て・禁止節は入れない。
  `exp/core-only-comparison` の `src/fdp/paper_core.c` に同じ構成の実装がある。
- 純素項: P のモデルの入力リテラルを N に仮定してUNSATコアを取り、1リテラルずつ削除して極小化する。
  これは Fried らの CORE 一般化（SAT 2024）で、既に比較済みの方式。3手法の出発点として使う。
- P は励起・Dチェーン・必須割当てを含むが、いずれも検出の必要条件なので、
  「入力キューブ内に検出入力が存在するか」の判定には正確に使える。
- FDPの分母、全PIの扱い、正常CNFの範囲限定は現行のまま。範囲外のPIは常にXになる。

## 4. 手法A: 順序付き被覆（決定リスト型）

### 考え方

通常の被覆では、どのキューブも単独で健全（全点が検出）でなければならない。
順序付き被覆では、キューブにラベル（検出／非検出）と順序を付け、
入力は**最初に一致したキューブ**のラベルに従うと決める。
すると k 番目のキューブは「それ以前のどのキューブにも入らない点」についてだけ正しければよい。
先に確定した領域をドントケアとして使えるので、後のキューブほど少ないリテラルで済む。

これは Rivest の決定リストにあたる。k-決定リストは k-DNF と k-CNF の和より真に広いクラスである
（Rivest 1987。分離の証明は後年の研究ノートで補正されている）。
桁上げ `c = OR_j(g_j AND AND_{i>j} p_i)` は、SOPでも補集合のSOPでも指数個の項が必要だが、
決定リストなら上位桁から「両方1なら検出、両方0なら非検出」と並べて 2n 本で書ける。
この例は机上の構成であり、今回の実測で確認したのは 2章の回路上の回数である。

### 手順

P と N の両方に、生成した全キューブの禁止節を入れる。禁止節は共通の活性化変数 g で保護する（`NOT g OR NOT cube`）。

1. 検出側の番: g を仮定して P を解く。UNSATなら未確定領域に検出入力は無いので完了（残りは非検出）。
2. モデルの入力リテラルを、`NOT g` を仮定した N に与えて純素項を作る（3章）。
3. g を仮定した N で、残ったリテラルをさらに1つずつ削除する。UNSATなら削除を採用する。
   これが「先行キューブを前提にした拡大」である。
4. キューブをラベル「検出」で登録し、禁止節を P と N に追加する。
5. 非検出側の番: P と N の役割を入れ替えて同じことを行う。g を仮定した N がUNSATなら完了（残りは検出）。
6. 検出側と非検出側を交互に繰り返す。

### 厳密性

不変条件: 登録済みの k 本について、「k 番目のキューブに入り、1〜k-1 番目のどれにも入らない点」は、
すべて k 番目のラベルどおりである。手順3のUNSAT（禁止節込みのオラクルに反対ラベルの点が無い）がこれを保証する。
したがって最初に一致したキューブのラベルは真の検出結果に等しい。
未確定領域 `NOT T` に対して、P のUNSATは「検出入力なし」、N のUNSATは「非検出入力なし」を意味する。

BDDは生成キューブだけから作る。順に `U := U OR (Q_k AND NOT T)`（検出ラベルのとき）、`T := T OR Q_k` とし、
N 側で終わった場合は最後に `U := U OR NOT T` を加える。上限で打ち切った場合の `P(U)` は下界である。

### 注意

- 検出ラベルのキューブは単独ではテストキューブではない（先行する非検出キューブに入る点を含みうる）。
  `-cube` の保存対象にはできない。
- 生成回数には非検出側のキューブも数える。`cube_cnt` と `-limit` はこの合計とする。
- 検出側と非検出側の配分は `-ordered_ratio` で変えられるようにする（既定 1:1）。2章のとおり最適な配分は回路に依存する。

## 5. 手法B: 擬似キューブ（パリティ制約の併合）

### 考え方

擬似キューブは GF(2) 上のアフィン部分空間で、`XOR(x_i, i in S) = b` という制約の積で表す
（Luccio・Pagli 1999 の pseudocube／SPP 形式）。通常のキューブは、全制約が1変数の場合にあたる。
`x1=0, x2=0` という2条件を `x1 XOR x2 = 0` の1条件へ併合すると、領域は `00` に `11` を加えた2倍になる。
t 回併合した擬似キューブは、通常キューブ 2^t 本分を1領域で表す。

線形座標（既存試作）は故障ごとに基底を先に決め、悪化する故障があった。
本手法は基底を決めない。領域ごとに、成立する併合だけをSATで採用する。
併合を1つも採用しなければ純素項そのものなので、領域あたりでは純素項より狭くならない。

### 手順

1. P のモデルから純素項を作り、各固定リテラルを1変数の制約とする。
2. 制約の対 (i, j) について、種パターンで両制約の代表変数を同時に反転した入力を故障シミュレーションする。
   非検出ならその併合は成立しないので捨てる（64パターン並列）。
3. 残った対を順に試す。2制約を1つのパリティ制約へ置き換えた全体を N に仮定し、UNSATなら採用する。
4. 採用が1つも無くなるまで 2〜3 を繰り返す。
5. `OR(NOT 制約)` を P の禁止節として追加し、領域を登録する。P がUNSATになれば完了。

パリティ変数は Tseitin の XOR 連鎖で必要時に定義し、P と N で同じ変数番号を使う。
BDDは制約ごとの XOR を AND して作る。

### 厳密性

採用した制約集合は必ず N のUNSATで確認済みなので、領域内の全入力が検出される。
シミュレーションは候補の足切りだけに使い、採用の根拠にはしない。
P には領域全体の否定を入れるので、P のUNSATは未被覆の検出入力が無いことを意味する。

### 注意

- 領域は通常のテストキューブではない。`-cube` の保存対象にはできない。
- 併合を重ねると3変数以上のパリティ制約になる。BDDは変数順によって大きくなりうる。
- 2章のとおり、効果は回路に依存する（s5378 では大きく、b14 の標本では小さい）。

## 6. 手法C: 窓関係（全数シミュレーション＋SAT反例）

### 考え方

種パターンと純素項から、幅 w（既定12、最大16）の入力集合 W を「窓」に選ぶ。
領域を `C_out AND [x_W が T に属する]` の形にする。`C_out` は素項の窓外リテラル、T は窓内の割当ての任意の集合である。
T は XOR、OR の組、桁上げなど窓内のどんな関係でも表せる。座標やブロックを事前に選ぶ必要がない。

SATの解を、一部の変数の値で回路をコファクタして得た関数へ一般化し、1回の列挙で大きな集合を捕える考え方は、
Ganai・Gupta・Ashar の circuit cofactoring（ICCAD 2004、SATベースの非有界モデル検査）にある。
ここでは窓内のコファクタを 2^w パターンの並列故障シミュレーションで表として求める。
窓外の「素項でXになった入力」まで自由にするため、SATの反例で表を絞る点が今回の応用である。

### 手順

1. P のモデルから純素項を作る（ケア集合 K）。
2. 窓 W を選ぶ。その故障でケアになった回数が多いPIを優先し、K から最大 w 本、足りなければ K 以外から補う。
3. 窓外の全PIを種パターンの値に固定し、窓内 2^|W| 通りを故障シミュレーションして表 T を得る。
4. N に「`C_out` かつ `x_W` が T に属する」を仮定して解く。
   SATなら反例（窓外の別の値で非検出になる入力）が得られる。その窓外値でもう一度表を作り、T との AND を取る。
5. 4 を UNSAT まで繰り返す。UNSAT時の T は、この窓と `C_out` に対して最大の健全な関係になる。
6. T を覆うキューブ群（ISOP）ごとに `NOT C_out OR NOT cube` を P に追加し、領域を登録する。

「x_W が T に属する」は、T の補集合を覆うキューブを活性化変数付きの節として N に入れて表す。
使用後は活性化変数を偽に固定する。

### 厳密性

手順5のUNSATが領域の健全性を直接保証する。
純素項は必ず領域に含まれる（素項内の点は検出されるので、反例による絞り込みで消えない）。
反例ごとに T から少なくとも1点が消えるので、絞り込みは 2^|W| 回以内に止まる。
P には領域を覆うキューブ群の否定を入れるので、完了判定は従来と同じ意味になる。

### 注意

- 生成回数は種の数で数える。1領域は通常キューブ数十〜数百本分に展開されうるので、展開数を別にログへ出す。
- 表やISOPが大きくなる場合に備え、キューブ数の上限を設けて素項へ戻す安全弁を置く。
- 利得は窓の選び方に依存する。今回の選択規則は単純な頻度順で、最適とは言えない。

## 7. 既存の制約との関係

| 条件 | A | B | C |
|---|---|---|---|
| パターン生成はSAT | 維持 | 維持 | 維持 |
| ドントケア判定を持つ | 非検出オラクルによる削除＋相対削除 | 削除＋パリティ併合 | 削除＋窓内全数シミュレーション＋SAT反例 |
| BDDは生成領域の和集合だけ | 維持（順序付きの差分和） | 維持 | 維持 |
| 回路の検出関数を直接BDD化しない | しない | しない | しない（窓内の表はシミュレーションで作る） |
| 完了は残余UNSAT | P または N のUNSAT | P のUNSAT | P のUNSAT |
| 出力が通常の 0/1/X キューブ | はい（順序とラベルが必要） | いいえ | 展開すれば通常キューブ |

手法Cの窓内の表は「検出関数の一部を全数評価する」処理であり、三段階の解釈としては境界にある。
窓幅を16以下に制限し、起点は必ずSATのパターンと素項にする。この扱いが研究上の条件に合うかは判断を仰ぎたい。
